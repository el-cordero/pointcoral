# Support

Start with the [website](https://el-cordero.github.io/pointcoral/), the
[Get started
guide](https://el-cordero.github.io/pointcoral/articles/pointcoral-workflow.html),
and the [function
reference](https://el-cordero.github.io/pointcoral/reference/).

Use [GitHub issues](https://github.com/el-cordero/pointcoral/issues) for
reproducible bugs and focused documentation requests. Include:

- the `pointcoral` and R versions and operating system;
- the input type and the function call;
- complete warnings or errors;
- whether image basenames are unique;
- CPCe and image coordinate dimensions and orientation, when relevant;
- the crosswalk column names and a synthetic example of affected labels;
  and
- a small synthetic reproducer plus
  [`sessionInfo()`](https://rdrr.io/r/utils/sessionInfo.html).

For a new CPCe file variant, describe its structure and attach only a
small redistributable fixture. Do not post confidential reef images,
exact locations of sensitive resources, credentials, client or project
identifiers, private crosswalks, or restricted ecological data in a
public issue.

Security-sensitive reports belong in the private channel described in
[SECURITY.md](https://github.com/el-cordero/pointcoral/blob/main/SECURITY.md).
