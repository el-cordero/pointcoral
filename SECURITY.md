# Security policy

The current 0.1.x release line receives security fixes. Older versions
may be asked to upgrade before a report is investigated.

Report suspected vulnerabilities privately to
<elvin.cordero@seamountgeo.com>. Do not open a public issue until the
maintainer has assessed whether disclosure could put users, data, or
systems at risk. Include the package version, R version, operating
system, affected function, expected impact, and a synthetic reproducer
when possible.

Never send credentials, confidential reef images, exact locations of
sensitive resources, client or project identifiers, private crosswalks,
or restricted ecological data. A package security policy does not
replace an organization’s review of image storage, site-location
confidentiality, model artifacts, or exported datasets.
