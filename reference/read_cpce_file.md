# Read one CPCe `.cpc` file

Reads the tested text `.cpc` format used by the bundled examples: header
row, four ROI vertices, point count, point coordinate rows, and point
label rows. If an image with the same basename is present next to the
`.cpc` file, image dimensions are read and `x_px`/`y_px` are calculated.

## Usage

``` r
read_cpce_file(path)
```

## Arguments

- path:

  Path to a `.cpc` file.

## Value

A tidy point table.

## Examples

pts <- read_cpce_file(cpc)
